# Mini R4: จากบล็อกสู่โค้ด

สื่อการสอน MATRIXblock Mini R4 คู่กับ Arduino C++ (`#include "MatrixMiniR4.h"`)

**เปิดเว็บ:** https://millerbankpbi.github.io/mini-r4-lessons/
เลือกภาษาเว็บได้ 3 ภาษา: ไทย / English / ລາວ (ปุ่มด้านบนเมนูข้าง)

| ไฟล์ | ใช้ทำอะไร |
|---|---|
| `index.html` + `data.json` | ตัวเว็บ (ต้องอยู่โฟลเดอร์เดียวกัน) |
| `KrubankR4-lessons-offline.html` | ไฟล์เดียวจบ ดับเบิลคลิกเปิดได้เลยแม้ไม่มีเน็ต (ฟอนต์จะเป็นฟอนต์เครื่อง) |
| `source/` | ต้นฉบับสำหรับเพิ่มบทเรียน (เนื้อหาไทยอยู่ใน `lessons_src.py`) |

## ภาษา

- เปิดครั้งแรกเป็นภาษาไทย (ถ้าเครื่องตั้งภาษาลาวจะเปิดเป็นลาว) และจำภาษาที่เลือกไว้
- ส่งลิงก์ให้เปิดเป็นภาษาที่ต้องการได้ด้วย `?lang=en` หรือ `?lang=lo` เช่น https://millerbankpbi.github.io/mini-r4-lessons/?lang=lo#u1-begin
- ป้ายบนบล็อกเลือกได้ English / ไทย (โปรแกรม MATRIXblock ไม่มีภาษาลาว หน้าลาวจึงใช้ป้ายอังกฤษเป็นค่าเริ่มต้น)
- คำแปล: `source/tr_en.py`, `source/tr_lo.py` (บทเรียน) และ `source/tr_en_blocks.py`, `source/tr_lo_blocks.py` (คำอธิบายบล็อก)
  ต้องมีจำนวนข้อ (เป้าหมาย ตัวอย่าง หมายเหตุโค้ด ลองทำ ตัวเลือกคำถาม) และลำดับเท่าฉบับไทยเสมอ
  `build_site.py` ตรวจให้ ถ้าไม่ตรงจะแจ้งเตือนและหน้านั้นจะแสดงภาษาไทยแทน
- ข้อความภาษาลาวแปลโดย AI ควรให้ผู้ใช้ภาษาลาวตรวจทานก่อนใช้จริง

โค้ดทุกตัวอย่างสร้างจากตัวสร้างโค้ดของ MATRIXblock Mini R4 v1.1.0 และคอมไพล์ผ่านกับบอร์ด UNO R4 WiFi 1.6.0 + ไลบรารี MatrixMiniR4 1.2.6
